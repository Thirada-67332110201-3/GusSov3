# บันทึกการใช้งานปัญญาประดิษฐ์ในการพัฒนาโครงงาน (AI Usage Log)
## GusSo E-Book Store (ระบบร้านจำหน่ายหนังสืออิเล็กทรอนิกส์)

**เอกสาร:** AI Prompting, Pair-Programming Log & Human-in-the-Loop Verification  
**เครื่องมือ AI ที่ใช้:** Google DeepMind Antigravity / Gemini / Claude  
**กรอบการทำงาน:** Responsible AI, Pair-Programming & Human Review  

---

## 1. วัตถุประสงค์และบทบาทของ AI ในโครงงาน

ในการดำเนินโครงงานระบบฐานข้อมูลร้านหนังสือดิจิทัล GusSo E-Book Store ทีมผู้พัฒนาได้ประยุกต์ใช้ **AI Coding Assistant** ในฐานะ **"คู่หูเขียนโค้ด (Pair-Programmer)"** เพื่อช่วยเร่งความเร็วในการออกแบบสถาปัตยกรรม เขียนสคริปต์ SQL วิเคราะห์ผลทางสถิติ และพัฒนาส่วนติดต่อผู้ใช้ (UI/UX) ให้ได้มาตรฐานสูงสุด 

โดยทุกกระบวนการมีสมาชิกในกลุ่มเป็น **ผู้กำกับ ควบคุมข้อกำหนด (Prompt Engineer)** และ **ตรวจสอบความถูกต้อง (Reviewer)** ทุกขั้นตอน

---

## 2. ประวัติและบันทึกการสั่งงาน (AI Prompt Log & Development Timeline)

### ระยะที่ 1: การออกแบบฐานข้อมูลเชิงสัมพันธ์และสคริปต์ SQL (Database Design & 3NF)
* **พรอมต์ที่ใช้:** 
  > *"ช่วยออกแบบโครงสร้างฐานข้อมูลร้านขาย E-Book ที่ได้มาตรฐาน 3NF ครบทุกตาราง พร้อมสร้าง ER Diagram แบบ Chen และ Crow's Foot รวมถึงสคริปต์สร้างตาราง Foreign Keys และจำลองข้อมูลคำสั่งซื้อ 30 ออเดอร์ย้อนหลัง 6 เดือนสำหรับทำรายงาน"*
* **ผลลัพธ์จาก AI:**
  - สร้างไฟล์ ER Diagram Report และตาราง Normalization (UNF -> 1NF -> 2NF -> 3NF)
  - เขียนสคริปต์ `supabase_setup_and_reports.sql` และ `supabase_seed_30_orders_monthly.sql`
* **การตรวจสอบโดยมนุษย์:**
  - ตรวจสอบความถูกต้องของ Foreign Key Constraints และตั้งค่า `ON DELETE CASCADE` ให้เหมาะสม
  - ตรวจสอบความสมจริงของยอดขายและวันที่ในคำสั่งซื้อทั้ง 30 รายการ

---

### ระยะที่ 2: การพัฒนาฟังก์ชัน Checkout แยกแท็บและการสั่งซื้อ (Multi-Tab E-Commerce)
* **พรอมต์ที่ใช้:**
  > *"อาจารย์แนะนำว่าระบบจ่ายเงินอยากให้แยกออกไปอีกแท็บนึงเหมือนเว็บขายหนังสือชื่อดัง ช่วยทำให้เมื่อกดชำระเงินจากตะกร้าจะเด้งไปอีกแท็บหนึ่ง (/checkout) และในหน้าคำสั่งซื้อให้รวมเป็นปุ่มชำระเงินเดียว ไม่ซ้อนกันหลายอัน พร้อมปุ่มกดย้อนกลับมาแท็บเดิม"*
* **ผลลัพธ์จาก AI:**
  - สร้างหน้า `app/checkout/page.tsx` รองรับการชำระเงิน บัตรเครดิต PromptPay และแนบสลิป
  - ปรับปรุง Cart Drawer ให้เปิดหน้าต่างใหม่ด้วย `window.open('/checkout', '_blank')`
  - ยุบรวมปุ่มชำระเงินที่ซ้ำซ้อนในหน้าประวัติคำสั่งซื้อให้เหลือปุ่มเดียวที่ Footer ของบิล
* **การตรวจสอบโดยมนุษย์:**
  - ทดสอบการกดชำระเงินจริงในเบราว์เซอร์ ยืนยันว่าเปิดแท็บใหม่ถูกต้องและกดกลับมาแท็บเดิมได้

---

### ระยะที่ 3: การปรับปรุง UI/UX, AI Book Advisor และการจัดการ State
* **พรอมต์ที่ใช้:**
  > *"หน้าเว็บรกไปหน่อย ปุ่มสลับธีมมืดสว่างให้แยกออกไปมุมซ้ายบนเหมือนคำถาม AI, ปรับให้ AI ตอบตรงคำถามเรื่องการลงทุนและการเงิน, และแก้บั๊กกล่องสุ่มค้างเวลาออกจากระบบ"*
* **ผลลัพธ์จาก AI:**
  - แยกปุ่ม Cyberpunk Theme Toggle เป็น Floating Widget ที่มุมซ้ายบน (`fixed top-20 left-4`)
  - อัปเกรด Logic ของ `components/ai-book-advisor.tsx` ให้จับคู่คีย์เวิร์ดการลงทุน การเงิน และโปรแกรมมิ่งได้แม่นยำ
  - ซ่อนปุ่มกล่องสุ่ม และรีเซ็ตเหรียญเป็น 0 ทันทีเมื่อผู้ใช้กดยืนยัน Logout ใน `components/navbar.tsx`
* **การตรวจสอบโดยมนุษย์:**
  - ทดสอบเปิด-ปิดกล่องสุ่ม ทดสอบกด Logout และตรวจเช็ค Contrast สีตัวอักษรให้อ่านง่าย

### ระยะที่ 4: การจัดทำชุดทดสอบอัตโนมัติและระบบ CI (Testing & CI Pipeline)
* **พรอมต์ที่ใช้:**
  > *"ช่วยเขียน Automated Test สำหรับตรวจสอบกฎความปลอดภัยราคาห้ามเป็น 0 หรือติดลบ, การคำนวณเงินในตะกร้า, และตรวจสอบ FK Integrity พร้อมตั้งค่า GitHub Actions CI Pipeline"*
* **ผลลัพธ์จาก AI:**
  - สร้างไฟล์ชุดทดสอบ `tests/system.test.mjs` รันด้วย Node.js Test Runner
  - สร้างไฟล์ `.github/workflows/ci.yml` รันอัตโนมัติเมื่อมีการผลักโค้ด
* **การตรวจสอบโดยมนุษย์:**
  - สั่งรันคำสั่ง `npm run test` ด้วยตนเอง ผลการทดสอบผ่าน 4/4 การทดสอบ (100% Pass)

## 3. สรุปคุณค่าที่ได้รับจากการประยุกต์ใช้ AI

1. **ลดระยะเวลาการพัฒนา (Productivity Boost):** ลดเวลาในการเขียนโค้ด Boilerplate และคำนวณสูตรทางสถิติลงกว่า 70%
2. **ยกระดับคุณภาพโค้ด (Code Quality & Robustness):** ได้รับคำแนะนำเรื่อง Type-Safety ใน Next.js 15 และการปฏิบัติตามมาตรฐานฐานข้อมูล 3NF
3. **การเรียนรู้เชิงลึก (Deep Learning Experience):** สมาชิกในกลุ่มได้ฝึกทักษะการตั้งโจทย์ (Prompt Crafting) การอ่านโค้ดเชิงวิเคราะห์ และการแก้ไขปัญหาจริงร่วมกับ AI
