# การออกแบบประสบการณ์ผู้ใช้และการเข้าถึง (User Experience & Accessibility Report)
## GusSo E-Book Store (ระบบร้านจำหน่ายหนังสืออิเล็กทรอนิกส์)

**เอกสาร:** User Persona, Wireframe Structure & WCAG Accessibility Audit  
**เกณฑ์มาตรฐาน:** User-Centered Design (UCD) & Web Content Accessibility Guidelines (WCAG 2.1 AA)  

---

## 1. กลุ่มผู้ใช้งานจำลอง (User Personas)

### Persona 1: ผู้อ่านและผู้ซื้อหนังสือ (Customer / Reader)
* **ชื่อ:** นายต้นกล้า เจริญผล (อายุ 21 ปี)
* **อาชีพ:** นักศึกษาคณะวิศวกรรมศาสตร์และเทคโนโลยี
* **เป้าหมาย (Goals):**
  - ต้องการค้นหาและซื้อหนังสือ E-Book ด้านเทคโนโลยีและโปรแกรมมิ่งอย่างรวดเร็ว
  - สามารถอ่านหนังสือบนเว็บได้สะดวก ไม่ต้องดาวน์โหลดแอปเพิ่ม
  - ซื้อแบบแพ็กเกจหรือใช้โปรโมชั่นลดราคา
* **จุดติดขัดเดิม (Pain Points):**
  - เว็บทั่วไปเวลากดชำระเงินมักจะเด้งทับหน้าเดิม ทำให้เลือกดูเล่มอื่นต่อไม่ได้
  - ตัวหนังสือในโหมดมืดบางเว็บกลืนกับพื้นหลัง อ่านโค้ดหรือรายละเอียดหนังสือไม่ชัดเจน
* **คุณลักษณะใน GusSo ที่ตอบโจทย์:**
  - ระบบ **Multi-Tab Checkout** เปิดแท็บจ่ายเงินแยกต่างหาก และมีปุ่มกดสลับกลับหน้าร้านทันที
  - ชั้นหนังสือ **3D Wooden Bookshelf** พร้อม **Page Flip Interactive Reader** เสมือนจับหนังสือจริง
  - **Cyberpunk Theme Contrast Fix** ปรับให้อ่านตัวอักษรได้คมชัดสบายตา

---

### Persona 2: นักเขียนและผู้สร้างคอนเทนต์ (Author / Creator)
* **ชื่อ:** ดร. ธนวัฒน์ หาญณรงค์ (อายุ 38 ปี)
* **อาชีพ:** อาจารย์พิเศษและนักเขียนอิสระด้านสถาปัตยกรรมระบบและฐานข้อมูล
* **เป้าหมาย (Goals):**
  - ต้องการช่องทางเผยแพร่หนังสือ E-Book เชิงวิชาการและคู่มือการพัฒนาซอฟต์แวร์
  - ต้องการตรวจสอบรายงานยอดขายของหนังสือที่ตนเองแต่งอย่างโปร่งใส
* **จุดติดขัดเดิม (Pain Points):**
  - แพลตฟอร์มส่วนใหญ่ไม่แยกข้อมูลบทบาทนักเขียน ชัดเจน ทำให้คำนวณส่วนแบ่งลิขสิทธิ์ยาก
* **คุณลักษณะใน GusSo ที่ตอบโจทย์:**
  - มี **Author Marketplace & Revenue Sharing (70/30)** ชัดเจนในฐานข้อมูล
  - หน้าโปรไฟล์ผู้แต่งและระบบแสดงผลงานของตนเอง

---

### Persona 3: ผู้ดูแลร้านและเจ้าของธุรกิจ (Store Admin)
* **ชื่อ:** คุณพิมพา สุขเกษม (อายุ 32 ปี)
* **อาชีพ:** ผู้จัดการฝ่ายปฏิบัติการร้านค้าดิจิทัล
* **เป้าหมาย (Goals):**
  - จัดการสต็อกหนังสือ หมวดหมู่ และแคมเปญลดราคารายสัปดาห์ได้ง่าย
  - อนุมัติสลิปโอนเงินรวดเร็ว และมีรายงานสรุปภาพรวมยอดขายที่เชื่อถือได้
* **คุณลักษณะใน GusSo ที่ตอบโจทย์:**
  - แผงควบคุม **Admin Dashboard** สรุปยอดขาย 30 ออเดอร์และรายงานวิเคราะห์ 4 เรื่องครบถ้วน
  - ฟอร์มเพิ่มหนังสือและหมวดหมู่แบบ **Two-Way Persistence** บันทึกลง Supabase และ Local State ทันที

## 3. ผลการตรวจสอบการเข้าถึง (Accessibility Audit Report - WCAG 2.1 AA)

การประเมินความสอดคล้องตามมาตรฐานสากล **WCAG 2.1 ระดับ AA** ได้ผลลัพธ์ดังนี้:

| หัวข้อเกณฑ์ (WCAG Criterion) | รายละเอียดการทดสอบ | ผลการตรวจสอบ | หมายเหตุและการปรับปรุง |
| :--- | :--- | :---: | :--- |
| **1.4.3 Contrast (Minimum)** | อัตราส่วนความเปรียบต่างของสีตัวอักษรกับพื้นหลัง | **PASS** (ผ่านเกณฑ์) | ปรับแก้สีข้อความใน Cyberpunk Theme และ Revenue Banner ให้ได้ค่า Contrast Ratio ≥ 5.2:1 (สูงกว่าเกณฑ์ 4.5:1) |
| **2.1.1 Keyboard Navigation** | การสั่งงานด้วยคีย์บอร์ดทั้งหมดโดยไม่ต้องใช้เมาส์ | **PASS** (ผ่านเกณฑ์) | สามารถใช้ปุ่ม `Tab`, `Enter`, และ `Space` นำทางและกดปุ่มได้ทุกฟังก์ชัน |
| **2.1.2 No Keyboard Trap** | ป้องกันการติดค้างของโฟกัสคีย์บอร์ด | **PASS** (ผ่านเกณฑ์) | หน้าต่าง Modal ของ Mystery Box และ Cart Drawer สามารถปิดได้ด้วยปุ่ม `Escape` ทันที |
| **1.1.1 Non-text Content** | มีคำอธิบายภาพ (Alt Text) สำหรับรูปภาพทั้งหมด | **PASS** (ผ่านเกณฑ์) | รูปหน้าปก E-Book ทุกเล่มมี `alt={book.title}` ชัดเจน |
| **2.4.4 Link Purpose** | วัตถุประสงค์ของลิงก์และปุ่มมีความชัดเจน | **PASS** (ผ่านเกณฑ์) | ปรับปรุงปุ่มในหน้าออเดอร์ให้รวมเป็นปุ่มชำระเงินเดี่ยวที่ชัดเจน ลดความสับสน |
| **3.2.2 On Input** | การทำงานไม่เปลี่ยนบริบทฉับพลันโดยที่ผู้ใช้ไม่รู้ตัว | **PASS** (ผ่านเกณฑ์) | การเปิดแท็บ Checkout มีการแจ้งและเปิดในหน้าต่างใหม่พร้อมปุ่มย้อนกลับ |
