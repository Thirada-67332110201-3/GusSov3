# เอกสารข้อกำหนดระบบ (System Specification)
## GusSo E-Book Store (ระบบร้านจำหน่ายหนังสืออิเล็กทรอนิกส์)

**รายวิชา:** ระบบฐานข้อมูล (Database Systems) — Mini Project  
**เวอร์ชันเอกสาร:** 1.0.0  
**สถานะ:** อนุมัติและพัฒนาเสร็จสมบูรณ์ (Production Ready)  

---

## 1. ภาพรวมของระบบ (System Overview)
GusSo E-Book Store เป็นเว็บแอปพลิเคชันพาณิชย์อิเล็กทรอนิกส์สำหรับการจัดจำหน่ายหนังสือดิจิทัล (E-Books) พัฒนาขึ้นด้วยสถาปัตยกรรม Full-stack ยุคใหม่ เพื่อรองรับผู้ใช้งาน 3 กลุ่ม ได้แก่ ผู้ดูแลระบบ (Admin), ลูกค้า/ผู้อ่าน (Customer), และนักเขียน/ผู้แต่ง (Author) โดยมีฐานข้อมูลเชิงสัมพันธ์ระดับ 3NF บน PostgreSQL (Supabase) ทำหน้าที่เก็บรักษาข้อมูลอย่างปลอดภัยและมีประสิทธิภาพ

---

## 2. ข้อกำหนดเชิงฟังก์ชัน (Functional Requirements: FR)

### FR1: การจัดการผู้ใช้และการควบคุมสิทธิ์ตามบทบาท (Role-Based Access Control - RBAC)
- **FR1.1:** ระบบต้องรองรับการระบุตัวตน 3 ระดับ: `admin` (รหัส 1), `customer` (รหัส 2), และ `author` (รหัส 3)
- **FR1.2:** ผู้ดูแลระบบสามารถเข้าถึงหน้า Dashboard จัดการร้านค้า (`/admin`) ได้
- **FR1.3:** ระบบต้องบันทึกประวัติผู้ใช้งาน และรองรับการสั่งซื้อทั้งแบบสมาชิกระบบและ Guest Customer

### FR2: การจัดการแคตตาล็อกหนังสือ E-Book
- **FR2.1:** ผู้ใช้สามารถค้นหาหนังสือตามชื่อเรื่อง นามปากกาผู้แต่ง หรือหมวดหมู่ได้แบบ Realtime
- **FR2.2:** ระบบต้องแสดงป้ายราคาโปรโมชั่นรายสัปดาห์ (Weekly Rotating Promotion) โดยมีมาตรการตรวจสอบราคาต้องไม่เป็น 0 บาท หรือติดลบ (`price > 0`)
- **FR2.3:** ผู้ดูแลระบบและนักเขียนสามารถเพิ่มหนังสือใหม่ ระบุชื่อ เรื่องย่อ ราคา ลิงก์รูปภาพหน้าปก และหมวดหมู่ได้

### FR3: ระบบตะกร้าสินค้าและการสั่งซื้อ (Cart & Multi-Tab Checkout)
- **FR3.1:** ผู้ใช้สามารถเพิ่ม/ลดหนังสือในตะกร้าสินค้า (Cart Drawer) คำนวณยอดเงินรวมได้อัตโนมัติ
- **FR3.2:** เมื่อกด "ชำระเงิน" ระบบจะเปิดหน้าชำระเงินในแท็บใหม่ (`/checkout`) เพื่อไม่รบกวนหน้าเลือกชมหนังสือเดิม
- **FR3.3:** ในหน้าชำระเงิน คำสั่งซื้อที่รอดำเนินการจะรวมเป็นบิลเดียวเพื่อความกระชับ ไม่ซ้อนกันหลายปุ่ม
- **FR3.4:** รองรับการชำระเงินผ่าน PromptPay QR Code, บัตรเครดิต, และการแนบภาพสลิปโอนเงินเข้าตาราง `payments`
- **FR3.5:** เมื่อชำระเงินเสร็จสิ้น มีปุ่มสลับกลับไปยังแท็บหลักของร้านค้าอย่างราบรื่น

### FR4: ชั้นหนังสือส่วนตัวและการเปิดอ่าน (My Bookshelf & Interactive Reader)
- **FR4.1:** ผู้ใช้ที่มีรายการคำสั่งซื้อสถานะ "ยืนยันแล้ว" จะได้รับสิทธิ์เข้าถึงหนังสือในชั้นหนังสือ 3D Wooden Bookshelf
- **FR4.2:** มีตัวเปิดอ่านหนังสือ Interactive Page Flip Reader จำลองการเปิดหน้ากระดาษแบบสมจริง
- **FR4.3:** ระบบสร้าง Token สำหรับดาวน์โหลดไฟล์ E-Book อย่างปลอดภัยผ่านตาราง `download_links`

### FR5: ระบบเกมมิฟิเคชัน (Daily Mystery Box Gamification)
- **FR5.1:** ผู้ใช้งานที่ล็อกอินมีสิทธิ์เปิดกล่องสุ่มรางวัลรายวันเพื่อรับเหรียญ Gus Coins
- **FR5.2:** ปุ่มกล่องสุ่มจะแสดงเฉพาะเมื่อผู้ใช้เข้าสู่ระบบ และจะซ่อนพร้อมรีเซ็ตค่าทันทีเมื่อออกจากระบบ (Logout State Protection)
- **FR5.3:** หน้าต่างกล่องสุ่มรองรับการปิดด้วยปุ่ม Esc หรือคลิกพื้นหลังภายนอกอย่างอิสระ

### FR6: ระบบ AI ผู้ช่วยแนะนำหนังสือ (AI Book Advisor)
- **FR6.1:** รับคำค้นหาหรือความสนใจของผู้ใช้ (เช่น เทคโนโลยี, การเขียนโปรแกรม, การเงินการลงทุน, พัฒนาตนเอง)
- **FR6.2:** วิเคราะห์คีย์เวิร์ดและบริบท จับคู่กับหนังสือที่มีอยู่ในคลัง และแสดงผลลัพธ์พร้อมเหตุผลในการแนะนำ

### FR7: การวิเคราะห์และรายงานผลสำหรับผู้บริหาร (Executive Analytical Reports)
- **FR7.1:** รายงานยอดขายตามช่วงเวลารายเดือน (Sales by Time Period)
- **FR7.2:** รายงานหนังสือขายดีที่สุด 5 อันดับแรก (Top 5 Best-Selling E-Books)
- **FR7.3:** รายงานสัดส่วนยอดขายตามหมวดหมู่ (Sales & Revenue by Category)
- **FR7.4:** รายงานพฤติกรรมการซื้อและมูลค่าตลอดชีพของลูกค้า (Customer Lifetime Value - CLV)

## 3. ข้อกำหนดเชิงคุณภาพที่ไม่ใช่ฟังก์ชัน (Non-Functional Requirements: NFR)

### NFR1: ประสิทธิภาพ (Performance)
- หน้าเว็บต้องเรนเดอร์เนื้อหาหลักแบบ Server-Side Rendering (SSR) ภายใน 1.5 วินาที
- ฐานข้อมูลต้องสร้าง Index บนคอลัมน์ที่ถูกค้นหาบ่อย ได้แก่ `ebooks.title`, `orders.created_at`, `orders.status`

### NFR2: ความมั่นคงปลอดภัยของข้อมูล (Security)
- โครงสร้างฐานข้อมูลสอดคล้องตามมาตรฐาน 3NF ป้องกันความซ้ำซ้อน
- มีข้อจำกัด Foreign Key Constraints และ Cascading Rules ครบถ้วน
- ข้อมูลผู้ใช้และการยืนยันตัวตนจัดการผ่าน Supabase Auth พร้อมเปิดใช้งาน Row Level Security (RLS)

### NFR3: การเข้าถึงและการใช้งาน (Usability & Accessibility)
- ส่วนติดต่อผู้ใช้รองรับมาตรฐาน WCAG 2.1 ระดับ AA
- มี Contrast Ratio ของตัวอักษรกับพื้นหลังมากกว่า 4.5:1 ทั้งในโหมด Cyberpunk Neon Dark และ Light Mode
- ออกแบบ Responsive รองรับการแสดงผลทุกขนาดหน้าจอ (Desktop, Tablet, Mobile)

### NFR4: ความพร้อมใช้งานและความเชื่อถือได้ (Reliability)
- ฐานข้อมูล PostgreSQL คลาวด์มี Uptime สูงกว่า 99.9%
- มีระบบ Dual Persistence ป้องกันข้อมูลสูญหายกรณีการเชื่อมต่ออินเทอร์เน็ตสะดุดชั่วคราว
